<h1>Chronic Clicker</h1>

<p>
Chronic Clicker is a passion project and early idle-incremental prototype. The core gameplay loop focuses on harvesting product, selling it for cash, and buying upgrades to increase production over time.
</p>

<br>

<p><strong>Current build:</strong> v0.0.1</p>
<p><strong>Engine:</strong> Godot</p>
<p><strong>Status:</strong> Early prototype</p>

<br>

<h2>Current Gameplay Loop</h2>

<ol>
	<li>Start the game from the title screen.</li>
	<li>Harvest product manually.</li>
	<li>Sell product for cash.</li>
	<li>Use cash to hire workers or farmers.</li>
	<li>Increase production through upgrades and automation.</li>
</ol>

<h2>Development Notes</h2>

<p>
This project was created as a solo learning prototype. The main goal of this build was to practice Godot fundamentals, including scenes, buttons, labels, signals, UI layout, basic economy logic, bug fixing, and simple idle-game automation.
</p>

<p>
The project is intentionally small and experimental. Future projects may use the lessons learned here to create cleaner code structure, better UI organization, save/load systems, and more scalable upgrade logic.
</p>
